# Invariantes

1. Tokens, `.env`, memórias pessoais, transcripts e caminhos locais nunca entram no repositório público.
2. Todo comando remoto de instalação aponta para uma versão explícita.
3. Cada artefato publicado possui SHA-256 e changelog correspondente.
4. Artefato versionado nunca é substituído silenciosamente; correção exige nova versão.
5. Documentação separa contexto versionado de memória nativa dos agentes.
6. Código, testes e configuração da fonte privada prevalecem sobre alegações históricas deste espelho de distribuição.
