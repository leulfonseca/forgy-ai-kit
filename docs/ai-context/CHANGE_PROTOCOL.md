# Safe change protocol

1. Anchor Git and test baseline.
2. Define changed and preserved behavior.
3. Map blast radius across product surfaces.
4. Implement the smallest coherent diff.
5. Run targeted and project-wide gates proportional to risk.
6. Review the diff and update durable context.

Para documentação, conferir links, versões e ausência de caminhos locais. Para release, validar SHA-256, changelog, GitHub Release e instalação do artefato remoto. Push, release e deploy exigem autorização atual.
