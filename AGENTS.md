# Regras do repositório de distribuição

- Este repositório público contém documentação e releases, não o ambiente privado de desenvolvimento.
- Não adicionar tokens, `.env`, memórias pessoais, transcripts ou caminhos locais.
- Manter comandos de instalação fixados em uma versão explícita.
- Publicar cada artefato com SHA-256 e changelog correspondente.
- Não substituir silenciosamente um artefato já versionado; criar uma nova versão.
- Em mudanças de documentação, preservar a distinção entre contexto versionado e memória nativa dos agentes.
